# E-commerce-BhStore
Loja virtual responsiva desenvolvida com HTML, CSS e JavaScript. Possui carrinho de compras, pesquisa dinâmica, LocalStorage, banner automático, menu responsivo e diversas interações utilizando JavaScript puro.

E-commerce Responsivo  Projeto de uma loja virtual desenvolvido com HTML, CSS e JavaScript puro, focado em praticar manipulação do DOM, lógica de programação e criação de interfaces modernas.  

Funcionalidades  - Banner automático. - Carrinho de compras. - Adicionar produtos ao carrinho. - Remover produtos do carrinho. - Alterar quantidade de produtos. - Cálculo automático do valor total. - Contador de itens do carrinho. - Barra de pesquisa em tempo real. - Lista de resultados da pesquisa. - Menu responsivo. - Mensagem de confirmação ao adicionar um produto. - Botão de WhatsApp. - Salvamento automático do carrinho utilizando LocalStorage.  

Tecnologias  - HTML5 - CSS3 - JavaScript (ES6)   

Objetivo - O objetivo deste projeto foi desenvolver uma loja virtual completa utilizando apenas HTML, CSS e JavaScript, sem frameworks, colocando em prática diversos conceitos estudados durante minha jornada de aprendizado.
